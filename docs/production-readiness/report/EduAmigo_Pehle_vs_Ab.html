EduAmigo: pehle kya tha, ab kya hai

Testing ka saar, aasaan bhasha mein. Tareekh: 25 October 2026. Testing aapke Mac par hui, 10 se 1,000 nakli users ke saath.

Seedha saar
  • Testing mein 1 badi dikkat mili: jab 1,000 log ek minute ke andar login karte the, login mein lagbhag 4 second lagte the. Ab sirf 0.06 second lagta hai. Ye theek ho gaya.
  • 4 chhoti-badi galtiyan app mein mili (phone par buttons chhup rahe the, vagairah). Sab theek ho gayi.
  • Ek school ka data doosre school ko kabhi nahi dikha, kisi bhi test mein.
  • Abhi 2,500, 5,000 aur 10,000 users ka test nahi hua. To ye kehna sahi nahi hoga ki EduAmigo 10,000 users sambhal lega. Abhi pakka sirf 1,000 tak hai, wo bhi sirf test setup mein.

4. Baaki testing ka nateeja

  • Live test, 4 Chrome windows mein (admin, teacher, student, parent ek saath): 37 mein se 37 pass. Matlab admin ne notice bheja to sirf wahi logon ko mila jinko milna tha. Homework, attendance, fee, chat, bus sab sahi logon tak pahunche, galat logon tak nahi.
  • 70 pages desktop aur phone dono par kholkar dekhe: ek ko chhodkar (upar ki galti) koi error nahi.
  • Permissions: 22 mein se 22 pass. Student, parent aur teacher doosre ke features nahi khol sakte. Save kiya hua data refresh aur logout/login ke baad bhi bacha raha.
  • Automatic tests: backend ke 1,294 pass.

5. Abhi kya pakka nahi hai

  • 2,500 se 10,000 users abhi nahi chale.
  • Fee payment, chat attachments, bus ki live location aur AI features load test mein abhi shaamil nahi hain. Bus ki location sabse bhaari ho sakti hai.
  • Ye test aapke Mac par hua, database bhi usi Mac par hai. Asli server aur asli internet par numbers alag honge.
  • Sirf Chrome par test hua. Safari, Firefox aur asli phone par nahi.
  • Kuch bhi commit, push ya deploy nahi kiya gaya. Saare badlav sirf aapke folders mein hain.

6. Aage kya karein

  1. Fee, chat aur bus-location load test mein jodkar 10 se 1,000 users dobara chalana.
  2. 2,500 users ka test (isme aapki "haan" chahiye).
  3. 5,000 aur 10,000 ke liye alag machine kiraye par aur asli jaisa test server.
  4. Live jaane se pehle badlav ko groups mein review karke commit karna.
